# 0041 — Telegram-style пузыри таймлайна (вариант B)

Дата: 2026-10-21. Статус: принято (реализация по шагам M-0…M-9, флаг по умолчанию off).

## Контекст

Текущий таймлайн (форк MatterMac) рисует плоскую Mattermost-сетку: аватар слева,
заголовок «имя · время», контент на всю ширину колонки. Все фреймы строки вычисляются
единым детерминированным `TimelineRowMetrics.messageLayout` и используются и для
`NSTableView`-высоты, и для отрисовки ячейки (`TimelineRowLayout.swift`). Целевой язык —
Telegram Desktop: входящие пузыри слева, тёмные, с аватаром; исходящие справа, синие,
без аватара; meta внутри пузыря; реакции и чип треда под пузырём; разделители дат по
центру (уже так). Прототип Open Design показал геометрию, но с инвертированной стороной
«своё/чужое» (`views.js:311` — `ctx.outgoing_pair` выставляется наоборот) и CSS-багом
`hidden`-оверлеев — эти баги не наследуем.

## Решение

1. Эволюция существующих слоёв, не параллельный класс ячейки: в `RowLayoutKey`/
   `RenderCacheKey` добавляется `styleKey`; `messageLayout` получает параметр
   `style: .flat | .bubble`; `MessageCellView` рисует фон-пузырь по фрейму
   `MessageRowLayout.bubble` с четырьмя радиусами (12 pt, сплюснутый угол 4 pt со
   стороны автора по `isContinuation`/`isLastInGroup`).
2. Core-изменение ровно одно, аддитивное: `PostPresentation.isLastInGroup` (хвост
   группы, в revision-хэшер рядом с `isContinuation`). Модель данных API не меняется.
3. Сторона пузыря = `AuthorPresentation.isCurrentUser` (своё — справа, синее).
   Системные/удалённые/unsupported-посты не заворачиваются в пузырь — остаются
   по центру как сервисные строки. Pending — пузырь исходящей стороны со своим
   `SendState`.
4. Текст рендерится с поверхностью (`MessageRenderer(surface:)`): `.outgoing` —
   светлый текст на синем в обеих темах (не `labelColor`), «(edited)» переезжает из
   тела в meta внутри пузыря. Поверхность — функция от автора сообщения, поэтому
   кэш рендеров не растёт.
5. Токены — в `TimelinePalette` (динамические: тёмная/светлая/высокий контраст);
   значения тёмной темы из brand-spec прототипа: исходящий `#2b5278`, входящий
   `#182533`, акцент `#64b5ef`.
6. Реакции и чип треда — под пузырём; hover-бар и панель реакторов сохранены как
   есть; строчная hover-подсветка ограничивается прямоугольником пузыря, flash
   прыжка к посту — полнострочный.
7. Включение — типизированный флаг `MatterMac.bubbleTimeline` в `LocalSettings`
   (стиль decision 0032), default off на время миграции; переключение прогоняет тот
   же сброс, что смена размера текста (токены обнуляются, высоты переоцениваются).

## Последствия

- Строки становятся выше (meta-линия) — paging и видимость меряются бенчмарками до/после;
  скролл-якоря не затронуты (механика не зависит от содержимого строки).
- Аватары входящих: 32 → 38 pt — отдельный шаг после стабилизации (цель даунсэмплинга
  пайплайна `TimelineMetrics.avatarSize`, тесты картинок обновить).
- Осознанные замены против flat-режима: полноширинная заливка self-mention-строки →
  рамка-серьёзность на пузыре + инлайн-подсветка; hover-время continuation-строк в
  левом gutter → в gutter стороны автора; «(edited)» в теле → в meta.
- Превью треда в чипе — деградация до «N ответов»: окно канала хранит только корни
  (ADR 0037). Полноценное превью — аддитивное поле `replyPreview` в v2.
- Meta на многострочниках — отдельной строкой в пузыре (детерминированно, один TextKit-
  проход); пиксельный TG-оверлей последней строки — v2.
- Flat-режим сохраняется полностью; все существующие тесты гоняют оба стиля.
