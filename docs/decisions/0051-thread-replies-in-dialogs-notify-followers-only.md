# 0051 — Ответы в тредах внутри диалогов уведомляют только подписанных

Дата: 2026-10-22. Статус: принято.

## Контекст

Репорт пользователя: уведомления приходят о replies в тредах, на которые он не
подписывался — треды начались в диалогах, где он не писал и не настраивал follow.
Резолюция
уровней в `NotificationPolicy` обслуживала ветку DM/GM раньше проверки follower'а,
поэтому **любой** ответ в треде внутри диалога уведомлял безусловно.

Сверка с исходниками обеих половин официального стека:

- Сервер v7.8 (`app/notification.go`): поле `followers` события `posted` — это
  `notificationsForCRT.Desktop`, подборка thread-follower'ов, уже отфильтрованная
  по `desktop_threads`, статусу и канальным overrides. В direct-каналах автор корня
  и упомянутые в корне НЕ попадают в автоподписку (в group-каналах — попадают).
- Веб-клиент v7.8 (`actions/notification_actions.jsx`): при уровне "all" ответ
  в треде (`isCrtReply`) не уведомляет без вхождения в `followers` — **независимо
  от типа канала, включая DM/GM**. При уровне "mention" `followers` сливается с
  `mentions`, после чего личные диалоги уведомляются целиком, а групповые — только
  по упоминанию/подписке.

## Решение

`NotificationPolicy.kind` для DM/GM:

- уровень "all": уведомляет любой обычный пост; ответ в CRT-треде (свёрнутые треды
  в MatterDock всегда включены, ADR 0037) — только при `notifiesThreadFollower`;
- уровень "mention": прямые диалоги уведомляют каждый пост (причуда официального
  клиента сохранена), групповые — упоминания и follower'ов треда.

Политика по-прежнему не подменяет серверную подборку локальными списками
подписок: локальное состояние follow неполное, `followers` из события — истина.

## Последствия

- Диалоговые треды без подписки больше не звонят при уровне "all" — паритет с
  официальным клиентом.
- Автоподписка сервера (упоминание в корне треда в GM, `ThreadAutoFollow`)
  продолжает приносить уведомления — это серверное поведение, присутствует и в
  официальном клиенте; MatterDock сознательно не подменяет его.
- Тесты: `collapsedThreadRepliesInDialogsRequireFollowersOnAll` покрывает обе
  ветки уровней и причуду "mention".
