# 0038 — Группировка непрочитанных каналов включена по умолчанию

Дата: 2026-10-21. Статус: принято.

## Контекст

Upstream включает «Group unread channels separately» только по явному выбору
пользователя (локально, в памяти). Пользователь форка хочет, как в официальном
клиенте: каналы с новыми сообщениями всегда видны вверху сайдбара.

## Решение

`DirectoryStore.groupsUnreads` по умолчанию `true`. Каналы поднимаются в группу
Unreads вверху: сначала с упоминаниями, затем по свежести активности. Замьюченные
каналы без упоминаний не поднимаются (то же правило, что у `unread`).

## Последствия

- Тумблер «Group unread channels» в меню View остаётся (локальное отключение).
- `SidebarShellTests` явно отключает группировку в начале прогона категорий
  (проверяет обычные секции, затем саму группировку — как раньше).
- Сортировка внутри секций не меняется: группировка только выносит непрочитанные.
