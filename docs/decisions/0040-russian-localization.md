# 0040 — Русская локализация интерфейса и выбор языка

Дата: 2026-10-21. Статус: принято.

## Контекст

Пользователь просит русский интерфейс и выбор языка в настройках приложения
(системного per-app выбора через «Системные настройки» недостаточно).
В upstream UI был только английский: каталог приложения
`Apps/MatterMac/Resources/Localizable.xcstrings` практически пуст, все
строки живут литералами в коде — `String(localized:)` в пакете разрезолвит
их через `Bundle.main` (документированное поведение: `bundle: nil` →
main bundle), а SwiftUI `Text("…")`/`Picker("…")`/`Button("…")` идут через
`LocalizedStringKey`.

Выбранный сервер (Time Messenger) локализаций клиента не касается; язык —
чисто клиентское предпочтение.

## Решение

1. **Каталог.** Ключи извлекаются из исходников скриптами
   `scripts/extract_localizable_keys.py` (Swift-литералы: плоские как есть,
   интерполяции → плейсхолдеры) и `scripts/verify_localizable_keys.py`
   (сквозная верификация: mini-пакет срабатывает компилятору с каталогом
   маркеров; все 115 интерполированных ключей совпали, `%lld`/`%@`/`%%`
   подтверждены). Итог — `ru`-значения в `Localizable.xcstrings` приложения.
   «MatterMac» в переводах заменяется продуктом форка «MatterDock»
   («Mattermost» как имя сервера остаётся). EN-ключи с упоминанием
   MatterMac не правятся — правка потянет бы каскад UI-тестов, хвост
   зафиксирован в docs/progress.md.
2. **Переключатель.** `LocalSettings.AppLanguage` (system/english/russian),
   ключ `MatterMac.language` (decision 0032 стиль: типизированный,
   валидируемый при чтении). При смене — яблоко `AppleLanguages` пишется в
   тот же storage (`UserDefaults.standard` приложения): стандартный
   механизм per-app языка, применяется при следующем запуске; UI честно
   об этом говорит («applies after MatterDock restarts»).
3. **Место в UI.** Settings ▸ General, первый контрол в локальной секции.

## Последствия

- `UserDefaults`-использование расширено ещё одним ключом внутри
  действующего решения 0032 (тот же домен `MatterMac.*` + системный
  `AppleLanguages`); SECRET §7 нарушений нет — ни сообщений, ни токенов.
- Пакетные тесты пишут `AppleLanguages` только в свой in-memory storage;
  в `environment(nil)` (memory-only) язык просто не сохраняется.
- Локализация новых строк форка производится повторной выжимкой
  (скрипты сохранены) и дополнением каталога.
