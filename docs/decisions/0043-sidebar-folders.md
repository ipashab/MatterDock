# 0043 — Папки сайдбара (folders rail)

Дата: 2026-10-21. Статус: реализовано полностью (фазы 1–5, коммиты
efaa5b8, ca643dd, 8c1ef13, 9f444cc, f5e2f39; фикс панели реакций 6e6593e).
Запрос владельца: «нужны разделы/папки как в основном клиенте» + ранний запрос:
группа «Все» по умолчанию и пользовательские группы рельсы, иконка
группа-эмодзи с подписью под ней).

## Контекст

Владелец просит организовать сайдбар по образцу веб-клиента и Telegram-папок:
узкая рельса слева от списка чатов, элемент — иконка и подпись под ней. Состав
рельсы (фазы 1–5):

1. «Все» — все чаты, поведение до папок (дефолт).
2. Пользовательские группы — серверные sidebar-категории (`kind` custom/managed/
   unknown) в серверном порядке; иконка — дефолтная папка или выбранное владельцем
   эмодзи (хранится локально, у серверной категории поля иконки нет).
3. «Обсуждения» — все треды, где я задействован (CRT-фид, фаза 2).
4. «Черновики» — незавершённые черновики (фаза 3).
5. «Упоминания и реакции» — упоминания по тегу и реакции на мои посты (фаза 4).
6. «Непрочитанные» — все чаты и группы с новыми сообщениями.

## Решение

1. **Тождественность**: `SidebarFolderID` (Core, `Presentation/SidebarFolder.swift`)
   — пять встроенных + `group(SidebarCategoryID)`; `rawValue` (`"all"`, …,
   `"group:<categoryID>"`) — форма локального хранения выбора. Элемент рельсы —
   `SidebarFolderItem` (kind/caption/categoryID/isMuted/unread/mentions/isAvailable);
   поставляется снапшотом (`SidebarSnapshot.folders`), нового I/O нет.
2. **Вторая колонка**: `SidebarSnapshot.chatSections(for:)` — выборка по папке.
   Группа — фильтр секций по `categoryID` (перестройки нет: hoisting непрочитанных
   и сортировки серверные); «Непрочитанные» — плоская секция `isUnread ||
   mentionCount > 0`, упоминания первыми; тред/черновики/упоминания колонку
   каналов не показывают (свои списки в фазах 2–4).
3. **Бейджи групп** считаются по членству категории через
   `DirectoryStore.unread(for:)`, не по строкам секции: hoisting непрочитанных
   уносит строку из секции, а бейдж группы обязан показывать её упоминания.
4. **Выбор**: `SessionViewModel.selectedFolder`, персистент —
   `MatterMac.selectedSidebarFolder`. Ключ глобальный, не по аккаунту: в
   `UserDefaults` (`LocalSettings`) не попадают идентификаторы аккаунтов (SPEC §7).
   Группа, удалённая на сервере, снимает выбор при публикации снапшота с
   загруженными категориями (до `usesServerCategories` не сбрасываем — папок ещё
   нет в первом снапшоте). Клавиатурная навигация (⌥↑/↓) ходит по секциям
   выбранной папки (`adjacentChannel(in:)`); при «Все» поведение байтово прежнее.
5. **Иконки групп**: `MatterMac.sidebarGroupIcons` — JSON `[categoryID: emojiName]`
   (≤100 записей, строки ≤64 байт, валидация при загрузке); неактивные/чужие
   значения молча отбрасываются. Выбор эмодзи — фаза 5 (контекстное меню пункта).
6. **Рельса** (`MatterMacUI/Shell/FolderRail.swift`, 64 pt, видна всегда):
   глиф + подпись 9 pt под ним; выбор — капсула у левого края + подложка глифа;
   красная капсула — упоминания, точка — непрочитанное. «Обсуждения» недоступны,
   если сервер выключил CRT (`isAvailable`). Ширина сплиттера увеличена на 64.

## Ограничения (честно)

- Реакций «на мои посты» в API Mattermost нет: папка упоминаний собирает
  упоминания поиском по `@username` + realtime-кольцо резидентных реакций
  (фаза 4); полная история реакций недостижима и показана не будет.
- Черновики остаются session-only (SPEC §7): папка — только текущей сессии.
- Управление составом групп — средствами сервера (веб-клиент); приложение
  показывает серверные категории, локально — только иконка.

Фаза 1 (рельса Все/группы/Непрочитанные + выбор + персистент) закрыта; фазы 2–5
в планах сессии.
