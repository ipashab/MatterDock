# 0058. Анимированные пользовательские эмодзи (GIF/APNG)

Дата: 2026-10-26. Статус: принято.

## Контекст

Пользовательские эмодзи сервера бывают анимированными (GIF, реже APNG),
репорт 2026-10-26: «Пользовательские смайлики бывают еще и гиф —
отображаются все статично, без анимаций». Конвейер изображений
(`ImagePipeline`) декодировал только первый кадр
(`CGImageSourceCreateThumbnailAtIndex`, индекс 0), а места показа —
вложение в тексте (`CustomEmojiAttachmentCell`), чип реакции, пикер и
панель отреагировавших — не имели механизма смены кадров.

## Решение

- **Декод.** Для источников с несколькими кадрами `ImagePipeline.decodePlan`
  возвращает `frameCount` (ограничен `maximumAnimationFrames = 16`),
  резерв памяти считается на все кадры, `Decoded` получает необязательную
  `Animation` — кадры и задержки (нулевые задержки выравниваются до 0,1 с,
  как в браузерах, иначе цикл схлопывается). В счётчик памяти и LRU идёт
  сумма кадров; высвобождение lease остаётся прежним. Статичные картинки
  декодируются как раньше — одним кадром.
- **Тактовик.** Один `EmojiFrameAnimator` на таймлайн (таймер 15 кадров/с
  в режиме `.common`, анимация не замирает при скролле) вместо таймера на
  каждую ячейку. Цели слабые; верхняя граница 64 одновременно анимируемых
  единиц, лишние деградируют в статичный первый кадр. Кадр выбирается по
  прошедшему времени (`frameIndex(at:)`), грязной помечается только зона
  эмодзи. `CADisplayLink` на macOS создаётся только от view — поэтому
  обычный `Timer`, точности 1/15 с для эмодзи достаточно.
- **Места показа.** В тексте сообщения — `AnimatedEmojiAttachmentCell`
  (наследник `CustomEmojiAttachmentCell`, геометрия не меняется). Чип
  реакции рисует текущий кадр сам. Пикер, превью по удержанию и панель
  отреагировавших используют `NSImageView.animates` с многослойным
  `NSImage` — AppKit перебирает кадры сам, свой механизм им не нужен.
- **Жизненный цикл.** Строка регистрирует свои анимированные цели при
  конфигурации/приходе картинки и снимает их в `releaseImageDemand`
  (уход строки, переиспользование); тактовик останавливается, когда целей
  не остаётся. Demand-регистрация не зависит от анимированности — lease
  кадра держится, пока строка на экране.
